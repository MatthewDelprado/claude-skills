# Bro

The user just read something complicated and wants it made easy. Re-explain it; don't add new work.

1. **Restate the last message in plain human language, with no jargon.** Say what it means and what, if anything, it asks of them. Same content, simpler words. Don't pad it, and don't re-run any work.

2. **If there are options, lay them out in a table.** One row per option, columns for the factors that best help them decide, and a clear recommendation (a "Recommended" marker or a line under the table).

3. **If we're deep in the detail of something, start with a very brief summary of what we're trying to do.** One or two sentences, before the restatement.

Keep the whole reply short. If the last message had no options, skip the table. If the conversation isn't deep in detail, skip the summary.
